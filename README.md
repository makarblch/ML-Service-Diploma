# ML-Service-Diploma
Repository for ML service of the research diploma Algorithms for Converting a Company Owner's Individual Income Into Turnover and Profit for the Company, 2026

Как запустить проект?

- зайти в корневую папку проекта
- выполнить команду docker compose up --build -d
- после этого проект будет запущен, можно будет отправлять запросы
